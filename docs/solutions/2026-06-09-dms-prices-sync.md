# Problem
При обновлении цен на добровольное медицинское страхование (ДМС) в Сербии возникла проблема рассинхронизации данных. Цены дублировались в нескольких независимых зонах страницы: в интерактивной таблице (объект `D`), в статических карточках компаний, в рекомендациях калькулятора (массив `recs` и массив рекомендаций по целям), в тултипах `TIPS` и в блоке лайфхаков/советов экспатов. При обновлении тарифов для компаний UNIQA и Triglav старые цены оставались захардкоженными в текстовых блоках.

# Root Cause
Отсутствие единого источника правды (Single Source of Truth) для ценовых данных в проекте. Цены прописаны вручную как в JS-объектах данных, так и непосредственно внутри HTML-верстки карточек, текстовых рекомендаций калькулятора и советов. Это привело к тому, что при точечном обновлении объекта `D` или карточек, старые цены (например, Wiener Basic за ~€90–120/год, UNIQA Start 1K за ~€189/год) оставались в других частях интерфейса.

# Solution
1. Произведено полное сканирование файлов `index.html` и `README.md` на предмет устаревших цен.
2. Синхронизированы тарифы во всех 7 ключевых зонах `index.html`:
   - Объект интерактивных данных `D` (UNIQA, Triglav, Wiener).
   - Карточки компаний (UNIQA, Triglav, Wiener, Dunav).
   - Результаты калькулятора по целям и бюджету (блок рекомендаций по ВНЖ и комфорту).
   - Тултипы `TIPS` (Triglav).
   - Блоки лайфхаков и советов (Wiener, Dunav).
   - Источники данных и подвал страницы (изменение даты проверки на `09.06.2026`).
3. Синхронизирована сводная таблица в `README.md` (добавлены актуальные диапазоны цен и новая компания Generali).
4. Проведена верификация с помощью поиска (grep) по старым ценовым значениям (189, 241, 649, 114, 90-120).

# Prevention
1. Перед коммитом изменений цен обязательно проводить сквозной текстовый поиск (grep/Select-String) по старым значениям тарифов.
2. В долгосрочной перспективе необходимо отрефакторить калькулятор и карточки компаний, чтобы они динамически подтягивали цены из единого JS-объекта конфигурации (например, `D`), исключая дублирование данных в верстке.
